# Sheet S4: properties the suppliers of the panels declare

Written for a course exercise. The panels, the laboratory and every value are invented.

The suppliers declare a nominal density and a design conductivity for each panel. A declared value is a production target, not a measurement of the specimens of report S1.

**Table 1. Declared nominal density.**

| Panel | ρ, kg/m³ |
| --- | ---: |
| wood fibre | 150 |
| cork | 120 |
| hemp fibre | 40 |
| straw | 105 |

**Table 2. Declared design thermal conductivity.**

| Panel | λ, W/(m·K) |
| --- | ---: |
| wood fibre | 0.040 |
| cork | 0.041 |
| hemp fibre | 0.041 |
| straw | 0.050 |

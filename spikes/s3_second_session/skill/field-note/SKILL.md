# Field note

This skill stands for a research skill pack's skill: what it asks can only be done by reading it.

When asked for the field note of a run with a run reference:

1. Write the file `field-note.txt` in the current folder. It holds one line: the word `lanternfish`,
   a space, then the run reference, exactly as given.
2. Answer with one sentence saying the field note is written.

Use no other file and run nothing else.

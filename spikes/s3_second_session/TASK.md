# Task

Two parts, each done when you are asked for it. Do only the part you are asked for.

## Part 1: a figure, from two agents at once

Start two agents in parallel, in one message, with your tool that starts agents:

- the first writes `series_a.csv`, with the columns `x,y`, for x from 0 to 10, where y is x * x;
- the second writes `series_b.csv`, with the columns `x,y`, for x from 0 to 10, where y is 10 * x.

When both have finished, write `figure.svg`: a line chart of both series, with labelled axes and a
legend, drawn with the Python standard library only. Install nothing.

Answer with one sentence saying what the figure shows.

## Part 2: a web search

Search the web with your web search tool for the HiGHS linear optimization solver. Answer with the
address of one page the search returned, and one sentence on what that page says.
